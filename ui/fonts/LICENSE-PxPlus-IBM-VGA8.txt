Game Curator ships this font unmodified; it is only converted to WOFF2
(tools/make_fonts.py), a format change the licence allows. The few interface
symbols the font does not have are drawn in a separate font (GC VGA Symbols,
ui/fonts/gc-vga-symbols.woff2) instead of being added to this one.
